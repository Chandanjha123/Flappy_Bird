# Flappy Bird Clone 🐦

A simple Flappy Bird clone built using Python and the Pygame library. The game mimics the popular Flappy Bird mechanics where the player controls a bird and navigates through obstacles.

## 📌 Features
- Classic Flappy Bird mechanics
- Smooth animations and physics
- Collision detection
- Score tracking
- Sound effects
- Responsive gameplay

## 🛠️ Technologies Used
- **Python** → Core game logic
- **Pygame** → Graphics, physics, and interactions

## 🚀 How to Run
1. **Clone the Repository**
   ```sh
   git clone https://github.com/Chandanjha123/Flappy_Bird.git
   ```
2. **Navigate to the Project Folder**
   ```sh
   cd Flappy_Bird
   ```
3. **Install Dependencies**
   ```sh
   pip install pygame
   ```
4. **Run the Game**
   ```sh
   python main.py
   ```

## 🎮 How to Play
- Press `Spacebar` to make the bird jump.
- Avoid hitting the pipes.
- Keep the bird in the air as long as possible to achieve a high score.
